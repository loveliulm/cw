# 企万万慧-财务软件源码（开源版）

#### 介绍
企万基开源财务软件，一款面向中小企业的轻量级财务管理工具。支持凭证管理、账簿报表、应收应付、收支流水等核心功能，界面简洁易上手。基于主流开源技术栈开发，部署灵活、可扩展性强，欢迎社区贡献与二次开发。
